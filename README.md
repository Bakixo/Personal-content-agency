# 🧠 Personal Content Agency  
AI destekli haber → içerik üretim platformu

news.smol.ai üzerinden güncel yapay zekâ haberlerini çekip,  
**Medium uyumlu makaleler** ve **sosyal medya içerik paketleri** üreten kişisel bir içerik ajansı.

---

## 🚀 Ne Yapıyor?

Bu proje şunları otomatikleştirir:

- 🔎 **news.smol.ai** üzerinden en güncel AI haberlerini çeker
- ✍️ Seçilen haberden:
  - Medium’a **direkt yapıştırılabilir** zengin içerik üretir
  - Kod blokları gerçek kod gibi görünür (Markdown değil, HTML)
- 📱 Aynı haber için:
  - Video script (Reels / TikTok)
  - Carousel (5 slide)
  - Kişisel teknik yorum üretir
- 🌐 Tüm bunları **tek bir web arayüzü** üzerinden yapmanı sağlar

---

## 🧩 Özellikler

- ✅ Medium uyumlu **saf HTML çıktı**
- ✅ Gerçek `<pre><code>` blokları (Medium’da bozulmaz)
- ✅ Sosyal medya için hazır içerik paketi
- ✅ Frontend + Backend tek deploy
- ✅ API base otomatik (local / prod fark etmez)
- ✅ Prompt’lar kolayca özelleştirilebilir
